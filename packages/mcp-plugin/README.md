# Novara Commerce McpPlugin

The `McpPlugin` exposes Novara Commerce's data and operations to AI agents via the [Model Context Protocol](https://modelcontextprotocol.io/).

`npm install @vendure/mcp-plugin`

For documentation, see [example.com/reference/core-plugins/mcp-plugin/](https://github.com/MarieHasson/novara-commerce/tree/master/docs/docs/reference/core-plugins/mcp-plugin/)
