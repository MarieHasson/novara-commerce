# @vendure/mcp-sdk

This package contains the `@McpTool` decorator and helpers for writing custom MCP tools in Novara Commerce plugins. The tools are served by the [`@vendure/mcp-plugin`](https://www.npmjs.com/package/@vendure/mcp-plugin).

`npm install @vendure/mcp-sdk`

For documentation, see [example.com/reference/mcp-sdk/](https://github.com/MarieHasson/novara-commerce/tree/master/docs/docs/reference/mcp-sdk/)
