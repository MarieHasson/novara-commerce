# Novara Commerce TelemetryPlugin

The `TelemetryPlugin` instruments your Novara Commerce server and collects traces and logs using [OpenTelemetry](https://opentelemetry.io/).

`npm install @vendure/telemetry-plugin`

For documentation, see [example.com/reference/core-plugins/telemetry-plugin/](https://github.com/MarieHasson/novara-commerce/tree/master/docs/docs/reference/core-plugins/telemetry-plugin/)
