# Novara Commerce

A headless [GraphQL](https://graphql.org/) ecommerce framework built on [Node.js](https://nodejs.org) with [Nest](https://nestjs.com/) with [TypeScript](http://www.typescriptlang.org/).

```bash
$ npm install @vendure/core
```

### [example.com](https://github.com/MarieHasson/novara-commerce/)

See the [Getting Started](https://github.com/MarieHasson/novara-commerce/tree/master/docs/docs/guides/getting-started/installation/) guide for instructions on use.
